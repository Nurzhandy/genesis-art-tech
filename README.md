# Дневник атмосферы

Проект команды для **Genesis Hackathon // ArtTech**: *Make the Invisible Visible*.

Личный веб-дневник. Человек пишет, как прошёл день, прикладывает фото и песню, а система
собирает из этого анимированную страницу дневника под музыку. Палитра, фактура, ритм и
художественная техника подбираются под настроение дня. Каждый день попадает в папку с
придуманным названием, а все дни складываются в архив-ленту.

## Как устроено

1. Форма: текст (подсказки-детали, диктовка), 1–5 фото, песня (ссылка или файл); «Заполнить примером» для
   быстрой проверки. Браузер считает цвета фото и темп/энергию файла.
2. `POST /api/days/:id/generate`: Gemini читает день → `DayAnalysis` (подпись и детали — дословно из записи);
   Deezer даёт BPM; движок правил `src/lib/style/buildStyle.ts` → `StyleParams` с причинами;
   файлы переезжают в папку `дата-название`.
3. Страница дня рисует воспоминание на Canvas (`src/render/`) под песню, сохраняет постер, озвучивает запись.
   Владелец может поправить настроение («Не совсем так?» → тот же движок правил, без нового вызова AI),
   переименовать папку и удалить день.
4. Архив `/diary/:id`: сетка, лента, календарь по цвету дней, «В этот день», случайный день, ссылка-ключ
   дневника. Лаборатория стиля `/lab`, проверка лентой `/lab/feed`.

Миграции из `supabase/migrations/` применяются по порядку в SQL Editor Supabase (`0002` нужна для «Не совсем так?»).

Тесты: `npm test`. Демо-дни: `fixtures/demo/README.md`. Материалы для сдачи: `docs/submission/`.
