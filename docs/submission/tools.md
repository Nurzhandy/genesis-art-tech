# Использованные инструменты

| Что | Для чего |
|---|---|
| Next.js 16, React 19, TypeScript, Tailwind CSS 4 | веб-приложение, API-роуты |
| Supabase (Postgres + Storage) | дневники, дни, приватные папки дней |
| Vercel | хостинг |
| Gemini API (`gemini-3.8-flash`, ответ JSON по схеме), Google Gen AI SDK | анализ текста и фото дня, название папки, подпись, оценка песни (темп, лад, жанр, год) |
| OpenAI TTS `gpt-4o-mini-tts` (опционально) / Web Speech API | озвучка записи голосом по правилам системы |
| Deezer API | BPM, год и официальное 30-секундное превью трека |
| oEmbed Spotify / YouTube | исполнитель и название по ссылке |
| web-audio-beat-detector, Meyda | темп, энергия и «яркость» своего аудиофайла в браузере |
| heic2any | фото с iPhone (HEIC) |
| JSZip | «Скачать папку» дня |
| sharp, tsx | скрипт демо-дней и фото-заглушки лаборатории |
| Vitest | тесты движка правил и пайплайна |
| Google Fonts: Cormorant Garamond, JetBrains Mono, Caveat | постоянная типографика дневника |

**Собственный вклад команды:** визуальная система и движок правил `buildStyle`, пять техник рендера на Canvas
(мазки, геометрия, минимализм, плёнка, коллаж), пайплайн дня, архив и интерфейс.
При разработке использовался AI-ассистент для программирования (Claude Code).
