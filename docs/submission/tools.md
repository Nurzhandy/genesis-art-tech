# Использованные инструменты

| Что | Для чего |
|---|---|
| Next.js 16, React 19, TypeScript, Tailwind CSS 4 | веб-приложение, API-роуты |
| Supabase (Postgres + Storage + Auth) | дневники, дни, доски, приватные папки дней; вход по почте и паролю, дневники аккаунта на любом устройстве |
| Vercel | хостинг |
| Gemini API (`gemini-3.8-flash`, ответ JSON по схеме), Google Gen AI SDK | анализ текста и фото дня, название папки, подпись, оценка песни (темп, лад, жанр, год); «Рассказать день» — устный рассказ (аудио) → запись дневника словами автора |
| OpenAI TTS `gpt-4o-mini-tts` (опционально) / Web Speech API | озвучка записи голосом по правилам системы |
| Web Speech API (`SpeechRecognition`, ru-RU) | диктовка записи голосом в форме, если браузер поддерживает |
| Open-Meteo (Geocoding, Archive, Forecast) | погода того дня по городу записи, без ключа |
| OpenStreetMap Nominatim (reverse geocoding) | место дня по GPS-меткам фото |
| MediaPipe Tasks Vision (`@mediapipe/tasks-vision`, модель selfie_multiclass) | маска людей на фото в браузере: люди прорисованы чётко, фон уходит в технику |
| page-flip | режим «Книга» в архиве |
| Web Audio API | процедурные звуки дня (шум, капли, треск), шорох страниц, громкость под озвучку |
| MediaRecorder, `canvas.captureStream` | видео дня 15/30/60 с и запись своего голоса |
| Deezer API | BPM, год и официальное 30-секундное превью трека |
| oEmbed Spotify / YouTube | исполнитель и название по ссылке |
| web-audio-beat-detector, Meyda | темп, энергия и «яркость» своего аудиофайла в браузере |
| heic2any | фото с iPhone (HEIC) |
| JSZip | «Скачать папку» дня |
| sharp, tsx | скрипт демо-дней и фото-заглушки лаборатории |
| Vitest | тесты движка правил и пайплайна |
| Google Fonts: Cormorant Garamond, JetBrains Mono, Caveat | постоянная типографика дневника |
| GSAP 3 (`gsap`, `@gsap/react`: ScrollTrigger, SplitText) | анимации лендинга на прокрутке: заголовки по словам, выезд примеров, «лист» с обещаниями |
| Lenis (darkroomengineering) | плавная прокрутка лендинга, главной и страницы дня |
| React Bits (DavidHDev/react-bits): ScrollReveal, StickerPeel, ClickSpark | манифест на лендинге, стикер «только ваш», который можно отклеить, искры по клику; код компонентов скопирован без изменений в `src/components/react-bits` с указанием источника |

**Собственный вклад команды:** визуальная система и движок правил `buildStyle` с объяснением каждого решения,
пять техник рендера на Canvas (мазки, геометрия, минимализм, плёнка, коллаж), режим «Рисунок», «живой кадр»
(свет часа, ритм баса, ветер, возраст дня), атмосфера и звуки дня, свободные доски дневника и дня со сборкой дня
из доски, заставка с частицами, архив и интерфейс.
При разработке использовался AI-ассистент для программирования (Claude Code).
