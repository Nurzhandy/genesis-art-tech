## Минимальные требования ТЗ (раздел 07)

| Требование | Где в прототипе |
|---|---|
| Ввод: текст, ≥1 фото, песня (ссылка или файл) | доска дня, простая форма, «Рассказать день» голосом |
| Вывод строится из ввода, а не из шаблона | движок правил `buildStyle`, 5 техник, «Почему так», «Как собран этот день» |
| Музыка влияет на оформление и звучит при просмотре | BPM → ритм кадров, год → пластинка/кассета/CD, жанр → техника; песня играет на странице, в «Войти в день», в коридоре и в видео |
| Отдельная папка дня с названием от системы | «Папка дня», `дата-название`: текст, фото, песня, анализ, стиль, постер, озвучка |
| Архив, вернуться к любому дню | сетка, коридор, книга, лента, календарь, «год в цветах», поиск |
| ≥3 дня с разным настроением | 7 демо-дней, 5 техник, 5 голосов |
| Свой вклад, указаны библиотеки и AI | [tools.md](tools.md) |
| Проверка по инструкции или видео | [jury-guide.md](jury-guide.md) + видео |
| Плюс: озвучка под атмосферу | Gemini TTS, голос по правилам (5 пресетов), свой голос |
