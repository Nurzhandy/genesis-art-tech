# Как проверить прототип

**Сайт:** https://genesis-art-tech.vercel.app — открывается без регистрации.
Лучше на компьютере в Chrome, Edge или Safari, со звуком.

## За 2 минуты: готовые дни

1. Откройте сайт. Первой идёт заставка «Какого цвета был твой вчерашний день?» — её можно пропустить кликом.
2. «Демо» в шапке сайта → демо-дневник: 7 дней с разным настроением. Переключите вид: сетка, **коридор** (прокрутка — прогулка по коридору, дни висят на стенах, звучат их песни),
   книга, лента, календарь, «год в цветах».
3. Откройте любой день, например [«Осенний ботанический сад и какао»](https://genesis-art-tech.vercel.app/day/b54ce047-bfa7-4a74-a286-97548e9c86c0)
   или [«Ночь в офисе перед сдачей»](https://genesis-art-tech.vercel.app/day/11314726-3303-4679-85bc-4076269f3459).
4. «Оживить день» — страница оживает под песню: кадры сменяются в её темпе, идёт погода того дня, крутится пластинка, звучат звуки дня.
5. «Послушать запись» — запись читает голос, выбранный правилами под настроение дня.
6. «Войти в день» — день разворачивается в 3D: слои на разной глубине, ведите мышью (на телефоне — наклоняйте его),
   погода летит перед лицом, звучат песня и голос записи.
7. «Как собран этот день» — постер раскладывается на 8 слоёв, у каждого подписана причина.
8. «Доска этого дня» — доска, на которой день собирали: заметки, фото, пластинка, капля настроения.
   Ниже на странице — «Почему этот день выглядит так», «Забрать» (видео 9:16 с песней и голосом, обои) и «Папка дня».

Сравните два дня подряд: одна система, одни постоянные элементы, но разные палитра, техника, ритм и голос.
Все семь рядом — [feed-7-days.jpg](feed-7-days.jpg), объяснение каждого — [examples.md](examples.md).

## За 5 минут: свой день

1. На главной — «Начать»: дневник заведётся на этом устройстве, без регистрации, и откроется ваш стол.
2. «＋ Записать день» — сразу пустая доска дня. (Со стола можно открыть и сам дневник: он раскрывается книгой, затем доской.)
3. Положите на доску: двойной щелчок — заметка о дне; перетащите 1–3 фото; ◉ — ссылка на песню
   (Spotify, YouTube, Яндекс Музыка или Deezer); по желанию — 🎙 голосовое и капля настроения.
4. «Собрать день». Сборка занимает около минуты: система читает запись и фото, слушает песню,
   узнаёт погоду, придумывает название папки и собирает страницу.

Есть и простая форма с полями — кнопка «простая форма» на доске дня; в ней же «Заполнить примером», если нет своих фото.

## Запуск у себя

Код: https://github.com/Nurzhandy/genesis-art-tech

```
git clone https://github.com/Nurzhandy/genesis-art-tech.git
cd genesis-art-tech
npm install
npm run dev
```

Без ключей сайт работает в локальном режиме: дневники и файлы сохраняются в папку `.local-data`,
а анализ дня — упрощённый, по словам и цветам. С ключами (`.env.example` → `.env.local`: Supabase и Gemini) —
как на сайте. Тесты: `npm test`.
