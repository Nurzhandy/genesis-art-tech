# Сценарий видео (до 3:00)

Снимаем на любимом дне команды (совет ТЗ, раздел 08): настоящие фото, та самая песня, запись «как другу».
Генерация дня идёт около 50 секунд — в монтаже её сокращаем, анимацию сборки оставляем целиком.
Заставку перед записью включить заново: `/?intro=1`.

| Время | Кадр | Текст за кадром |
|---|---|---|
| 0:00–0:12 | Заставка: «Какого цвета был твой вчерашний день?» → буквы рассыпаются → частицы собираются в постер → «Теперь — видно» | «Фото помнят, как выглядел день. Но не как он ощущался.» |
| 0:12–0:22 | Лендинг: манифест проявляется по словам на прокрутке, «Начать» | «Начать можно без регистрации.» |
| 0:22–0:35 | Главная → стол → дневник открывается книгой → камера влетает в доску дневника | «Каждый дневник — свободная доска, где лежат ваши дни.» |
| 0:35–1:15 | «＋ день» → пустая доска дня: заметка о дне, перетаскиваем 3 фото, ◉ ссылка на песню (пластинка с обложкой), голосовое, капля настроения «уют» и «восторг» | «Кладу на доску всё, что запомнилось: пару строк, фото, ту песню и как я себя чувствовал.» |
| 1:15–1:30 | «Собрать день»: элементы слетаются в страницу | «Одна кнопка — и доска становится воспоминанием.» |
| 1:30–2:00 | Страница дня: постер → «Оживить день» — кадры в ритме песни, погода того дня, крутится пластинка, звуки дня; переключатель «Рисунок» | «Песня задаёт ритм, фото — палитру, погода того дня — дождь в кадре.» |
| 2:00–2:15 | «Почему этот день выглядит так»: 4 главные причины, «Все причины» | «Каждое решение объяснимо: никакой случайной картинки.» |
| 2:15–2:28 | «Папка дня»: название по смыслу записи, файлы; «Забрать»: видео и обои | «Система сама называет папку дня и складывает в неё всё: текст, фото, песню, постер и озвучку.» |
| 2:28–2:50 | Архив: доска дневника с карточками дней → книга с шорохом страниц → лента из 5–7 разных дней рядом → «Год в цветах» | «Разные дни, разные техники — и всё равно один дневник одного человека.» |
| 2:50–3:00 | Финальный кадр любимого дня, звучит песня | «Откройте запись через год — и снова почувствуйте тот день.» |

**Перед съёмкой:** в демо-дневнике должно лежать 5–7 настоящих дней с разным настроением
(спокойный, напряжённый, грустный, весёлый, ностальгический), на проде — ключ OpenAI для озвучки.
