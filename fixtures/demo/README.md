# Любимые дни команды для демо

Каждый день — отдельная папка:

```
fixtures/demo/
  osenniy-park/
    text.md      ← как прошёл день, как рассказали бы другу (погода, свет, запахи, люди, мелочи)
    date.txt     ← 2026-10-18
    song.json    ← {"kind":"link","url":"https://open.spotify.com/track/…","provider":"spotify"}
    photos/      ← 1–5 настоящих фото дня (jpg/png/heic)
```

Нужно 5–7 дней с разным настроением (ТЗ: минимум 3). Только свои или добровольно
предоставленные тексты и фото. Песни — ссылками, файлы чужих песен не кладём.

Загрузка в демо-дневник:

```bash
ALLOW_DEMO_WRITES=1 npm run dev
```
```bash
BASE_URL=http://localhost:3000 npx tsx scripts/seed-demo.ts
```

Потом откройте каждую выведенную ссылку — постер сохранится сам.
